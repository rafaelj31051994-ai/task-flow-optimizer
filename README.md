Objetivo

O Task Flow Optimizer é um sistema desktop de gerenciamento de tarefas desenvolvido como parte do Projeto Integrador do curso de Ciências da Computação. Seu objetivo é facilitar a organização, o acompanhamento e o controle de tarefas, permitindo que os usuários gerenciem suas atividades de maneira prática.

Funcionalidades

- Login e acesso ao sistema.
- Cadastro e gerenciamento de usuários.
- Criação, consulta, edição e exclusão de tarefas.
- Definição de prioridades, prazos e status das tarefas.
- Visualização de informações no painel principal.
- Calendário para acompanhamento das atividades.
- Geração de relatórios.
- Gerenciamento de equipe.
- Configurações do sistema, incluindo personalização do tema.
- Integração com banco de dados MySQL.

Requisitos e execução

O projeto foi desenvolvido em Java com interface gráfica Java Swing, utilizando Maven para gerenciamento das dependências e MySQL para armazenamento dos dados.

Para executar o sistema, é necessário ter o Java, o Maven e o MySQL instalados, configurar a conexão com o banco de dados e importar o script SQL disponibilizado na pasta "banco_de_dados".
